GenAI · Enterprise · Architecture
Enterprise RAG System
Internal knowledge retrieval for enterprise documents.
› Expand case study
Problem

Enterprise documents contain large amounts of information that are difficult to locate through conventional search — a conversational layer makes that knowledge easier to access.

What I found

Naive text chunking produced context loss and weak citation quality — chunk boundaries didn't align with document structure, which hurt retrieval precision.

What I did

Investigated document-layout-aware ingestion as an alternative to simple text splitting, rather than accepting the first pipeline that technically worked.

+40% retrieval speed
Lesson

In RAG, the ingestion strategy matters as much as the model — retrieval quality is an architecture problem before it's a prompting problem.

Deep Learning · CV · Experimentation
Rock Pile & Hole Segmentation
Semantic + instance segmentation for mining site safety.
› Expand case study
Problem

Detect and segment geological/industrial hazard regions (rock piles, holes) from mining-site imagery to support safety and automation workflows.

Approach

Built the dataset through large-scale manual polygon annotation, then trained DeepLabv3 and YOLO26-based models for semantic and instance segmentation, using rule-based Roboflow annotation workflows to improve label consistency.

Challenges
  • Class imbalance and small target regions
  • Mask resizing and interpolation effects on segmentation quality
  • Balancing annotation throughput against label precision
~88% mIoU (experimental result, specific model iteration)
Lesson

Dataset quality was as decisive as model choice — most of the real gains came from annotation strategy and preprocessing, not architecture tuning.
